# 🎨 Mockups de Alta Conversión

Este directorio almacena el diseño visual (assets, videos, y código MVP frontend) con el único objetivo de deslumbrar al prospecto en la fase de prospección.

**Reglas de los Mockups:**
1. **Calidad > Cantidad:** Deben lucir como agencias élite. Se fomenta el uso de animaciones (Framer Motion), bento grids, y videos generados por IA (Higgsfield).
2. **Reutilización:** Lo que se crea aquí se debe poder reciclar para múltiples clientes de este mismo nicho cambiando solo logos, copy y colores.
3. **No Funcionalidad:** El mockup no necesita backend complejo ni base de datos real. Es puramente la promesa de valor visual enfocada en UX/UI.
