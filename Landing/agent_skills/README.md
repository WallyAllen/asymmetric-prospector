# 🧠 Agent Skills para Landing

Aquí se deben almacenar los archivos `.md` de skills (instrucciones) diseñados específicamente para el equipo de agentes de desarrollo web. 

**Ejemplos de skills a desarrollar en este directorio:**
- `ui_component_assembler.md`: Instrucciones para consumir componentes React de 21st.dev y unirlos de manera coherente con Tailwind, priorizando estética "Silicon Valley".
- `cro_architect.md`: Instrucciones para estructurar la landing enfocada en retención y conversión, usando el copy adecuado y llamadas a la acción (CTAs) estratégicas basadas en analítica.
- `cloudflare_deployer.md`: Instrucciones precisas para que el agente despliegue la infraestructura edge-nativa y configure las bases de datos D1 minimizando costos.
