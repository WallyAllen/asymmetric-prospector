# 🚀 Landing Project - Motor de Conversión Multimedia

Este directorio centraliza la creación y gestión de "Motores de Conversión Multimedia" (páginas web y embudos de alta gama enfocados en CRO y diseño premium).

## 📂 Estructura de Directorios

- `agent_skills/`: Skills específicas para los agentes encargados de ensamblar componentes UI (ej. desde 21st.dev) y estructurar las páginas con un enfoque Data-Driven.
- `nichos/`: Organizado por industrias objetivo. Dentro de cada nicho encontrarás:
  - `mockup/`: Repositorio de componentes, prototipos Figma/código e integraciones multimedia (Higgsfield.ai) diseñados para generar un "efecto wow" en la prospección. No es un producto final, es la carnada visual.
  - `landings/`: Proyectos reales desarrollados para clientes que han mostrado interés o han sido cerrados, usando Vercel para MVPs y Cloudflare (Pages + Workers + D1) para el producto final.
